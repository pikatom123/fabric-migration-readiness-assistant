FABRIC MIGRATION READINESS AND OPTIMISATION ASSISTANT
Hackathon presentation bundle

START HERE
1. Open output/Fabric_Migration_Readiness_Assistant_Hackathon_Deck.pptx.
2. Play output/Fabric_Migration_Readiness_Assistant_2min_Demo.mp4 for the full-screen prototype walkthrough.
3. Use output/Fabric_Migration_Readiness_Assistant_Demo_Script.txt for the live-demo runbook and narration.

TEAM TESTING
- Share output/Fabric_Migration_Readiness_Assistant_Team_Test_Bundle.zip.
- It includes the standalone HTML, a 20-workload mixed assessment at 62% readiness, guarded negative cases, expected results, and a feedback template.
- Recipients extract the ZIP and open Fabric_Migration_Readiness_Assistant.html directly in Edge or Chrome.

DEMO INPUTS
- output/Contoso_Estate_Inventory.xlsx
  Customer inventory template for Excel. Save/export as CSV before browser upload.
- output/Contoso_Estate_Inventory.csv
  Browser-ready spreadsheet export. Imported rows remain Needs Discovery.
- output/Contoso_Estate_Overview.pdf
  Text-based PDF for the packaged import-estate CLI or Copilot discovery workflow.
- Manual entry
  Open index.html and use Add workload during the customer conversation.

IMPORTANT BOUNDARIES
- The browser page directly supports CSV and manual entry.
- PDF extraction runs through the CLI or Copilot workflow; the browser does not infer PDF facts.
- Native .xlsx upload is not implemented; use the included CSV export.
- Capacity information is directional input for the Fabric SKU Estimator, not a capacity quote.
- Recommendations must be validated with current Microsoft Learn guidance and representative workload telemetry.

REBUILDING
1. Run demo-assets/source/generate_bundle.py with Python packages: python-pptx, Pillow, reportlab, XlsxWriter.
2. In demo-assets/walkthrough, run npm install and npx playwright install chromium.
3. Run node demo-assets/walkthrough/record_walkthrough.mjs to capture the prototype.
4. Run node demo-assets/walkthrough/capture_roadmap.mjs to render the closing frame.
5. Run demo-assets/source/generate_narration.ps1.
6. Run demo-assets/source/build_video.ps1; FFmpeg is discovered from PATH or Winget.
7. Run demo-assets/source/build_team_test_bundle.ps1 to rebuild the shareable test ZIP.
