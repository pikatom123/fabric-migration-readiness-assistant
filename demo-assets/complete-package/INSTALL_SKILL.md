# Install the Workspace Skill

1. Extract the complete ZIP.
2. Copy the contents of `05-Copilot-Workspace/` into the root of a trusted VS Code workspace.
3. Open that workspace in VS Code.
4. Approve or start the `microsoft-learn` MCP server from `.vscode/mcp.json`.
5. Open Copilot Chat and select the **Fabric Adoption Discovery** agent, or ask to run a Fabric adoption readiness assessment.
6. Keep customer engagement files outside the reusable skill repository.

The skill is workspace-scoped and team-shareable. Its maintenance protocol is under `.github/skills/fabric-adoption-readiness/references/MAINTENANCE.md`.
