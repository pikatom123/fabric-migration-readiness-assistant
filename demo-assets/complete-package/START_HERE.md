# Fabric Migration Readiness and Optimisation Assistant - Complete CSA Package

This package combines the hackathon story, working prototype, validated test scenarios, future architecture, reusable CSA workflow, and workspace skill.

## Recommended order

1. `01-Presentation/` - use the deck to explain why, who, customer value, and maintained-skill model.
2. `02-Video/` - play the two-minute full-screen prototype walkthrough.
3. `03-Prototype-and-Testing/` - open the standalone HTML and upload one of three assessed industry CSVs.
4. `04-Future-Architecture/` - review production architecture, roadmap, controls, and CSA reuse playbook.
5. `05-Copilot-Workspace/` - copy the provided `.github` and `.vscode` folders into a trusted VS Code workspace to use the skill and agent.
6. `06-Assessment-Engine/` - install and run the deterministic Python engine and tests.

## What is current

Product support changes over time. The package intentionally does not claim that static guidance is permanently current. The skill retrieves Microsoft Learn evidence during each assessment and includes a maintenance protocol for reviewed rules updates.

## Customer-data boundary

The package contains fictional test data only. Store real customer files in a separate engagement folder, never in the shared source repository or reusable package.
